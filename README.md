# Aranya Landing Page (SSR)

Official landing page for **Aranya by Rang Homes** (Aerocity, Dharapur, Guwahati).

## Architecture: Server-Side Rendering (SSR) & SEO Optimization

This application has been converted from client-side rendering (CSR) to **full Server-Side Rendering (SSR)** for search engine visibility (SEO) and performance:

1. **Full SSR HTML Pre-rendering**:
   - Web crawlers (Googlebot, Bingbot, social media crawlers) immediately receive the full 120KB+ semantic HTML inside `<div id="root">` with headings, copy, image alt tags, floor plans, and amenities.
   - Zero empty white screen on load.
   - Near-instant First Contentful Paint (FCP) and Largest Contentful Paint (LCP).

2. **Full Client Hydration**:
   - The browser hydrates the server-rendered DOM via `ReactDOM.hydrateRoot()` in [src/entry-client.jsx](file:///src/entry-client.jsx).
   - Interactive features (2BHK/3BHK floor plan tabs, lead enquiry modal, gallery lightbox, FAQ accordion, cursor animations) work seamlessly.

3. **Production Optimization**:
   - Replaced heavy in-browser `@babel/standalone` (~2.5 MB) and development scripts with a pre-compiled, minified client bundle built with `esbuild`.
   - Node server serves with `gzip` compression and HTTP cache headers for static assets.

4. **SEO Enhancements**:
   - Primary Meta Tags (`title`, `description`, `keywords`, `robots`).
   - Open Graph (OG) tags for Facebook, LinkedIn, WhatsApp link previews.
   - Twitter Card tags.
   - Schema.org JSON-LD Structured Data: `ApartmentComplex`, `RealEstateListing`, and `FAQPage` rich snippets for Google search results.

## Getting Started

### Enquiry webhook configuration

Use Node.js 22 or newer. Create `.env` using `.env.example` and set `PABBLY_WEBHOOK_URL` to the Pabbly webhook URL. The Node server reads this file at startup; restart it after changing the value. `.env` is excluded from Git and blocked from local HTTP access.

Both the main enquiry modal and coming-soon form POST to `/api/leads`. The server forwards form fields (including the selected `interest` code, such as `2bhk` or `3bhk`), page URL, form source, UTM fields, and server-generated `date` (`dd/mm/yy`), `time` (`hh:mm:ss AM/PM`, 12-hour), `submitted_at` (date and time), and `timezone` (`Asia/Kolkata`). Phone numbers are validated and forwarded as 10 digits. Success is displayed only after the webhook returns a successful HTTP status.

For Cloudflare Workers, use build command `npm run build` and deploy command `npx wrangler deploy`. The checked-in `wrangler.jsonc` uploads only `site/`, generated by the build, and routes `/api/leads` to the Worker. Set `PABBLY_WEBHOOK_URL` as a runtime secret under the `aranya-lp` Worker's Settings → Variables and Secrets (not only in build variables). Local Wrangler preview reads `.env`; Git deployment does not upload it. Run `npm run build` before `npm run preview` or `npm run deploy` locally.

The `site/` folder contains the rendered HTML pages (`index.html`, `coming-soon.html`, `thank-you.html`, `thank-you-coming-soon.html`), browser bundles, and uploads. Dependencies, server bundles, source maps, source files, and `.env` are excluded. The build checks every asset against Cloudflare's 25 MiB limit. Cloudflare serves `coming-soon.html` at `/coming-soon` and `thank-you.html` at `/thank-you` using its default HTML routing.

Run `node --test tests/leads.test.cjs` to check payload handling and Kolkata timestamps using a mock webhook.

### 1. Install Dependencies
```bash
npm install
```

### 2. Build for Production (SSR & Hydration Bundle)
```bash
npm run build
```
This bundles the client hydration script into `dist/client.js`, compiles the server renderer into `dist/entry-server.cjs`, and generates pre-rendered SSR HTML in `index.html`.

### 3. Run the SSR Server
```bash
npm start
```
The server will start at `http://localhost:3000/`:
- **Coming Soon Page**: `http://localhost:3000/coming-soon` (or `/coming-soon.html`)
- **Full Landing Page**: `http://localhost:3000/` (or `/index.html`)
